# 🧪 テストガイド - ローカル開発環境でのテスト手順\n\n## 📋 前提条件\n\n- Node.js 18.x 以上\n- npm または yarn\n- Git\n- Firebase プロジェクト（セットアップ済み）\n\n## 🚀 セットアップ手順\n\n### 1. リポジトリをクローン\n\n```bash\ngit clone https://github.com/knz-group/knz-homepage.git\ncd knz-homepage\n```\n\n### 2. 依存関係をインストール\n\n```bash\nnpm install\n```\n\n### 3. Firebase を設定\n\n**重要**: `docs/FIREBASE_SETUP.md` を確認して、Firebase プロジェクトを作成してください。\n\n#### 3-1. `.env.local` ファイルを作成\n\n```bash\ncp .env.local.example .env.local\n```\n\n#### 3-2. Firebase 認証情報を入力\n\n[Firebase Console](https://console.firebase.google.com) から以下の情報をコピーして `.env.local` に貼り付けます：\n\n```\nNEXT_PUBLIC_FIREBASE_API_KEY=your_actual_api_key\nNEXT_PUBLIC_FIREBASE_AUTH_DOMAIN=your-project.firebaseapp.com\nNEXT_PUBLIC_FIREBASE_PROJECT_ID=your-project-id\nNEXT_PUBLIC_FIREBASE_STORAGE_BUCKET=your-project.appspot.com\nNEXT_PUBLIC_FIREBASE_MESSAGING_SENDER_ID=your-sender-id\nNEXT_PUBLIC_FIREBASE_APP_ID=your-app-id\n```\n\n### 4. 開発サーバーを起動\n\n```bash\nnpm run dev\n```\n\nブラウザで `http://localhost:3000` にアクセスします。\n\n---\n\n## 🧬 テストシナリオ\n\n### **テスト 1️⃣: ホームページの表示**\n\n**目的**: UI とナビゲーションが正しく表示されるか確認\n\n**手順**:\n1. `http://localhost:3000` にアクセス\n2. 以下が表示されることを確認：\n   - ナビゲーションバー（VendingViewer ロゴ）\n   - ホームページのヒーローセクション\n   - 機能説明セクション\n   - 最近投稿された機械セクション\n\n**期待結果**:\n- ページが正常に読み込まれ、スタイルが適用されていること\n- ログイン/登録ボタンが表示されていること\n\n---\n\n### **テスト 2️⃣: ユーザー登録**\n\n**目的**: Firebase認証でのユーザー登録機能をテスト\n\n**手順**:\n1. ナビゲーションバーの「登録」ボタンをクリック\n2. `/auth/signup` ページが表示されることを確認\n3. 以下の情報を入力：\n   - 表示名: `テストユーザー`\n   - メールアドレス: `test@example.com`\n   - パスワード: `Test1234`\n   - パスワード確認: `Test1234`\n4. 「登録する」ボタンをクリック\n\n**期待結果**:\n- 登録に成功して `/machines` ページにリダイレクト\n- ナビゲーションバーにメールアドレスが表示される\n- Firebase Console の Authentication で新規ユーザーが確認できる\n\n**トラブルシューティング**:\n- エラー「Firebase is not initialized」 → `.env.local` を確認\n- エラー「Auth domain is not valid」 → Firebase の認証ドメインを確認\n\n---\n\n### **テスト 3️⃣: ログイン・ログアウト**\n\n**目的**: ユーザーのセッション管理をテスト\n\n**手順**:\n1. ナビゲーションバーの「ログアウト」ボタンをクリック\n2. ログアウトされたことを確認（メールアドレスが消える）\n3. 「ログイン」をクリック\n4. 登録時のメール・パスワードでログイン\n5. 「ログイン」ボタンをクリック\n\n**期待結果**:\n- ログインに成功して `/machines` ページにリダイレクト\n- ナビゲーションバーにメールアドレスが表示される\n- ローカルストレージにセッション情報が保存される（ブラウザのデベロッパーツール確認可）\n\n---\n\n### **テスト 4️⃣: 機械一覧ページ**\n\n**目的**: 検索・フィルタリング機能をテスト\n\n**手順**:\n1. ナビゲーションバーの「一覧」をクリック\n2. `/machines` ページが表示されることを確認\n3. サンプル機械が3個表示されることを確認\n4. **フィルタリングをテスト**:\n   - 「都道府県」で「大阪府」を選択 → フィルタリングが適用される\n   - 「機械種別」で「おやつ」を選択 → フィルタリングが適用される\n   - 「並べ順」で「人気順」を選択 → 並び順が変わる\n5. 機械カード（左側）の内容を確認\n\n**期待結果**:\n- フィルタリングが正常に機能すること\n- 機械カードに画像、名前、住所、タグが表示されること\n- 閲覧数とお気に入り数が表示されること\n\n---\n\n### **テスト 5️⃣: 機械詳細ページ**\n\n**目的**: 機械の詳細情報が正しく表示されるか確認\n\n**手順**:\n1. `/machines` ページで機械カードをクリック\n2. `/machines/[id]` ページが表示されることを確認\n3. 以下が表示されることを確認：\n   - 大きな機械画像\n   - 機械の詳細情報（名前、住所、評価、製造者など）\n   - 商品リスト\n   - 「お気に入り」ボタン\n4. 「お気に入り」ボタンをクリック\n5. ボタンの色が変わることを確認\n\n**期待結果**:\n- 詳細ページが正常に読み込まれること\n- すべての情報が正確に表示されること\n- お気に入りボタンが機能すること（ただしローカルステートのため、ページリロードで初期状態に戻る）\n\n---\n\n### **テスト 6️⃣: 投稿ページ（認証チェック）**\n\n**目的**: 認証保護が正しく機能するか確認\n\n**手順**:\n1. ログアウト状態で `/submit` にアクセス\n2. ログインが必須であることを示すメッセージが表示されることを確認\n3. 「ログイン」をクリックしてログイン\n4. ログイン後、再度 `/submit` にアクセス\n5. 投稿フォームが表示されることを確認\n\n**期待結果**:\n- ログアウト状態では投稿フォームが表示されないこと\n- ログイン後、投稿フォームが表示されること\n\n---\n\n### **テスト 7️⃣: 機械投稿フォーム**\n\n**目的**: 新規機械の投稿機能をテスト\n\n**手順**:\n1. ログインして `/submit` にアクセス\n2. 以下の情報を入力：\n   - 機械の名前: `テスト自動販売機`\n   - 機械タイプ: `飲料`\n   - 説明: `これはテスト用の自動販売機です`\n   - 都道府県: `東京都`\n   - 住所: `東京都渋谷区テスト1-1-1`\n   - 緯度: `35.6762`\n   - 経度: `139.6503`\n   - タグ: `test, demo`\n3. 「投稿する」ボタンをクリック\n\n**期待結果**:\n- 「自動販売機を投稿しました！」という成功メッセージが表示される\n- フォームがリセットされる\n- Firebase Console の Firestore で `vending-machines` コレクションに新しいドキュメントが追加される\n\n**トラブルシューティング**:\n- エラー「緯度経度が無効」 → 数値形式を確認\n- エラー「Firestore へのアクセス拒否」 → Firebase のセキュリティルールを確認\n\n---\n\n### **テスト 8️⃣: プロフィールページ**\n\n**目的**: ユーザー情報の表示と編集機能をテスト\n\n**手順**:\n1. ログイン状態で `/profile` にアクセス\n2. ユーザー情報が表示されることを確認\n3. 「プロフィール編集」ボタンをクリック\n4. 表示名を変更（例: `テストユーザー改`）\n5. 「変更を保存」をクリック\n6. ページがリロードされ、新しい表示名が表示されることを確認\n\n**期待結果**:\n- プロフィール情報が正常に表示されること\n- 編集が正常に保存されること\n- Firestore の `users` コレクションが更新されること\n\n---\n\n## 🐛 ブラウザ開発者ツールでのデバッグ\n\n### Console タブ\n\n```javascript\n// Firebase の初期化確認\nconsole.log(firebase);\n\n// 現在のユーザー情報を確認\nimport { getAuth } from 'firebase/auth';\nconst auth = getAuth();\nconsole.log(auth.currentUser);\n```\n\n### Application / Storage タブ\n\n1. **Local Storage** → Firebase セッションが保存されているか確認\n2. **Session Storage** → 一時的なセッション情報を確認\n3. **Cookies** → Firebase の認証クッキーを確認\n\n### Network タブ\n\n1. ネットワークリクエストをチェック\n2. Firebase へのリクエスト（/firestore, /auth など）が成功しているか確認\n3. ステータスコードが 200 であることを確認\n\n---\n\n## 📊 Firebase Console での検証\n\n### Authentication\n\n1. [Firebase Console](https://console.firebase.google.com) にアクセス\n2. プロジェクト → Authentication\n3. 登録したユーザーが表示されることを確認\n4. ユーザーのメール、作成日時などを確認\n\n### Firestore Database\n\n1. Firebase Console → Firestore Database\n2. 以下のコレクションを確認：\n   - **vending-machines** → 投稿した機械が表示される\n   - **users** → ユーザー情報が保存される\n   - **reviews** → レビュー情報（後で追加）\n\n### Cloud Storage\n\n1. Firebase Console → Storage\n2. 画像アップロード機能実装後に確認\n\n---\n\n## ⚡ よくあるトラブルとその対処法\n\n| 問題 | 原因 | 解決策 |\n|-----|------|--------|\n| \"Firebase is not initialized\" | `.env.local` が未作成または誤設定 | `.env.local.example` をコピーして設定を確認 |\n| \"Cannot read property 'uid' of null\" | ユーザーがログインしていない | ログイン状態を確認 |\n| \"Permission denied\" (Firestore) | セキュリティルールが厳しすぎる | Firebase Console でルールを確認・修正 |\n| ページが真っ白 | React エラー | ブラウザコンソールを確認 |\n| 画像が表示されない | Cloud Storage のURL が異なる | ブラウザコンソールのネットワークタブを確認 |\n| ホットリロードが機能しない | ファイルのインポート方法が間違っている | `import` 文を確認 |\n\n---\n\n## 🎯 テスト完了チェックリスト\n\n- [ ] ホームページが表示される\n- [ ] ユーザー登録が成功する\n- [ ] ログイン・ログアウトが正常に機能する\n- [ ] 機械一覧ページが表示される\n- [ ] フィルタリングが正常に機能する\n- [ ] 機械詳細ページが表示される\n- [ ] 投稿ページが認証保護されている\n- [ ] 機械を投稿できる\n- [ ] Firebase Firestore に機械情報が保存される\n- [ ] プロフィール情報が表示・編集できる\n- [ ] Firebase Console で検証できる\n\n---\n\n## 🚀 次のステップ\n\nすべてのテストが完了したら、以下の機能を追加できます：\n\n1. **画像アップロード** - Cloud Storage への写真アップロード\n2. **レビュー機能** - ユーザーレビュー・評価\n3. **地図統合** - Google Maps での機械位置表示\n4. **検索機能** - テキスト検索\n5. **通知機能** - Firebase Cloud Messaging\n6. **デプロイ** - Vercel / Firebase Hosting へのデプロイ\n\n---\n\n## 📞 サポート\n\n問題が発生した場合：\n\n1. ブラウザコンソールのエラーメッセージを確認\n2. `docs/FIREBASE_SETUP.md` を再確認\n3.
